# Security Policy

`flutter_full_restart` can delete app data, so we take security reports seriously.

## Supported versions

| Version | Supported |
|---------|:---------:|
| 1.x     | ✅ |

## Reporting a vulnerability

**Please don't report security issues in public GitHub issues.**

Report them privately in one of these ways:

- Use GitHub's [private vulnerability reporting](https://github.com/azerosoft/flutter_full_restart/security/advisories/new).
- Email **hello@azerosoft.com** with the subject `Security: flutter_full_restart`.

Please include:

- the affected platform(s) and package version,
- a description of the issue and its impact,
- steps or code to reproduce it.

## What happens next

- We acknowledge your report within **3 business days**.
- We keep you updated while we investigate and work on a fix.
- Once a fix is released, we publish a security advisory and credit you, unless you prefer to stay anonymous.
